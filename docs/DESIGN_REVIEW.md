## 1. v0 진단 — 왜 "투박해" 보이는가

| # | 문제 | 원인 | v1 처방 |
|---|---|---|---|
| 1 | **시각 요소가 서로 싸운다** | 여권 표지 그라데이션, 줄무늬 종이 질감, 대각선 패턴, 그림자, 금테, 잉크 번짐이 한 화면에 모두 있음 | 장식 대부분을 걷어내고 **지도와 도장 두 가지만 주인공**으로 |
| 2 | **이모지를 아이콘으로 사용** | 탭, 버튼, 핀, 배지가 모두 이모지 → OS마다 모양이 다르고 장난감처럼 보임. **Windows는 국기 이모지를 "DE" 같은 글자로 표시** | UI 아이콘은 Lucide 선 아이콘으로 통일하고, 국기는 **SVG 원형 국기**로 |
| 3 | **서체 4종 혼용** | Playfair(세리프), Gowun Dodum(한글), Space Mono, Courier | **Pretendard 한 가족**으로 통일하고, 도장 숫자에만 모노스페이스 사용 |
| 4 | **색이 너무 많고 위계가 없다** | 네이비, 골드, 크림, 레드, 도장 잉크 7색, 파스텔 육지가 동시에 쓰임 | 무채색 베이스에 **포인트 컬러 1개(스탬프 레드)**만 |
| 5 | **지도가 주인공이 아니다** | 헤더와 통계 카드가 첫 화면의 1/3을 차지해 지도가 아래로 밀림 | **지도 풀스크린**으로 두고, 정보는 위에 떠 있는 작은 알약(pill) 하나로 |
| 6 | **메뉴와 선택지가 많다** | 탭 4개, 공유, 설정, 필터 칩 3개, 폼 입력 6개 | 화면 1개 + 바텀시트 1개. 기록은 **원탭 체크인**, 상세는 나중에 선택 |
| 7 | **지도 정보 밀도가 낮다** | 47개 점이 모두 같은 모양이라 중부유럽에 뭉침. 라벨 없음, 방문해도 보이는 게 없음 | 줌 레벨별로 정보를 단계적으로 보여주고, **방문한 도시 주변만 상세 지도가 열림** |
| 8 | **도장이 클립아트 같다** | 거친 필터, Courier 서체, 가운데 이모지 | 선 1~2개와 타이포그래피만 쓰는 **절제된 라인 도장** |

**잘 된 점 (유지):** 도시마다 다른 도장, "쾅" 하고 찍히는 순간의 피드백, 집에서 뻗어 나가는 궤적, 공유 카드 개념.

## 2. v1 컨셉 — "안개 걷기 (Lift the Fog)"

> 유럽 전체는 **옅은 구름 안개에 덮인 흑백 지도**. 도시를 방문하면 그 자리에 **둥근 렌즈**가 열리며
> **거리, 강, 공원, 구시가지 지붕이 살아있는 컬러 상세 지도**가 드러난다.

- 한눈에 "내가 어디를 가봤는지"가 **면적**으로 보입니다. 점이 아닌 구멍으로 보여 시인성이 높아요.
- 방문할수록 지도가 실제로 **완성되어 가는** 경험을 줍니다 (게임의 Fog of War).
- 줌인하면 내가 걸었던 동네의 실제 골목까지 보이니 기록장으로서의 가치도 큽니다.

### 줌 레벨별로 보이는 것

| 줌 | 보이는 것 |
|---|---|
| **유럽 전체** (z3–5) | 구름 안개 위에 **국기 퍼즐**: 방문한 조각만 그 나라 국기의 해당 부분으로 칠해짐. 나라마다 `독일 5/12` 태그, 다 채운 나라는 `오스트리아 완성`. 미방문 나라는 안개 속 이름만 |
| **나라** (z5–8) | 빈 조각은 점선 윤곽으로 보여 다음 목표가 됨. 방문 도시 위에 렌즈(z13 상세 지도 스냅샷)와 도시명 태그, 도시 점 (등급별 크기 3단계) |
| **도시** (z8+) | 렌즈 대신 실제 안개 구멍: 방문 도시 반경 안은 상세 지도(한글 라벨), 바깥은 안개 |

> **렌즈가 필요한 이유:** 실제 지리 반경(10~20km)으로 안개를 걷으면 유럽 전체 화면에서는 1~2px이라 보이지 않아요.
> 줌이 낮을 때는 화면 크기 기준의 렌즈로 "가봤다"는 사실을 크게 보여주고, 확대하면 진짜 지도로 자연스럽게 넘어갑니다.

## 3. 정보 구조 (IA) — 화면 1개 + 시트 1개

```
┌──────────────────────────────┐
│ (23개 도시 · 9개국)      (●) │  ← 진행률 알약 / 프로필 버튼
│                              │
│                              │
│        풀스크린 지도          │
│    (안개 + 열린 도시들)       │
│                              │
├──────────────────────────────┤
│ 🔍 어디 다녀오셨어요?         │  ← 바텀시트 (peek)
│ 🇩🇪🇫🇷🇮🇹🇦🇹 …  방문한 국기 줄    │
└──────────────────────────────┘
```

| 영역 | 역할 | 상태 |
|---|---|---|
| **지도** | 앱의 99%. 탭하면 도시/국가 상세 | 항상 |
| **바텀시트** | 검색 + 나라 목록 + 상세가 모두 이 안에서 열림 | peek → half → full |
| **프로필** (우상단) | 통계, 배지, 타임라인, 공유 카드, 설정·백업 | 전체 화면 페이지 1개 |

**없애는 것:** 하단 탭바, 필터 칩, 별도 여권/기록/배지 탭. 배지는 획득하는 순간 토스트로 보여주고, 프로필에서만 모아 봅니다.

### 핵심 플로우: 체크인 (탭 2번)

1. 시트의 검색창 탭 → "프라" 입력 (한글, 영어, 현지어 모두 검색) **또는** "📍 현재 위치"
2. "프라하" 탭 → **즉시 도장 + 안개 걷힘 애니메이션** → 날짜는 오늘로 자동 입력
3. (선택) 시트에 뜬 `사진 추가` · `한 줄 남기기` · `날짜 변경` 버튼 — 무시해도 됨
4. 실수로 찍었으면 토스트의 `되돌리기`

> 기존 6칸 폼 → **필수 입력 0개**. 기록은 "남기고 싶을 때만" 덧붙입니다.

### 국기 퍼즐 — 채울수록 완성되는 국기

나라마다 대표 도시(tier 1~2, 나라당 3~12곳)를 기준으로 국토를 **보로노이 분할**해 조각을 만들어요.
**조각 = 그 대표 도시의 "지역"**("뮌헨 지역")이고, 소도시는 가장 가까운 대표 도시의 조각에 속해요.
행정구역 데이터는 쓰지 않아요. 경계가 정확할 필요는 없고 도시 좌표만으로 600개 넘는 도시 전체에 적용돼요.

- 조각 안의 도시를 **하나라도** 방문하면 그 조각이 칠해져요
- 칠하는 그림은 그 나라 국기를 나라 전체 크기로 펼친 것이고, 칠해진 조각 모양으로만 보여요. 다 채우면 국기가 나라 모양으로 완성돼요
- 국기는 줄무늬와 십자만 도형으로 그려요. 문장(스페인, 포르투갈 등)은 생략해요
- 채도는 82%, 불투명도는 92%로 안개 톤과 맞춰요. 조각 경계에는 흰 실선, 빈 조각에는 점선을 써요
- 다크 모드에서는 국기의 검정을 `--flag-black`(#4A4B50)으로 올려 배경과 구분해요
- 완성 연출: 마지막 조각을 칠하면 국기가 한 번 반짝이고, 태그가 "완성"으로 바뀌고, 시트의 국기 링이 금색이 돼요

> 시안: concept.html의 "국기 퍼즐" 섹션 (독일 1 → 5 → 12 조각 진행 예시 포함)

### 재방문과 히스토리

같은 도시를 여러 번 가는 건 자연스러운 일이에요. **방문 한 번 = 기록 한 건**으로 쌓고, "정복"은 도시 단위로 셉니다.

| 어디서 | 어떻게 보이나 |
|---|---|
| **지도** | 렌즈의 도시명 태그에 방문 횟수 배지(`프라하 3`). 자주 간 도시일수록 렌즈와 안개 구멍이 조금씩 넓어짐 (방문 1회 기준 +12%씩, 최대 +36%) |
| **체크인** | 이미 간 도시를 다시 찍으면 같은 흐름으로 바로 기록되고 토스트는 "프라하 3번째 방문". 같은 날 같은 도시는 중복 대신 기존 기록을 엶 |
| **도시 상세** | 도장이 겹겹이 쌓인 스택(최신이 맨 위), "3번 방문 · 총 6일", 첫 방문/최근/사진 수, **방문 타임라인**(최신순: N번째 · 날짜 · 머문 기간 · 메모 · 사진), 하단에 "다시 방문 기록"(지난 날짜로 소급 가능) |
| **시트 [도시] 탭** | 방문한 도시를 최근 방문순으로, 횟수 표시 `×3` |
| **프로필** | 도시 수(고유)와 별개로 총 방문 수, "가장 많이 간 도시" 3곳, 전체 방문 타임라인 |
| **배지** | 또 왔어요(재방문), 단골(같은 도시 5번), 사계절 프라하(한 도시를 네 계절 모두) |
| **공유** | 도시 카드 "프라하와 나 · 3번의 방문" (쌓인 도장 + 날짜들) |

**데이터 모델:** `visits(id, cityId, date, endDate?, note, photos[], createdAt, updatedAt)` — 도시당 여러 건.
`endDate`가 있으면 머문 기간("2박")을 계산. 통계는 고유 도시 수와 방문 수를 구분해서 셉니다.

### 타이포그래피 — Pretendard Variable

| 스타일 | 크기/굵기 | 용도 |
|---|---|---|
| Display | 32 / 700, 자간 -2% | 도시명 (상세) |
| Title | 20 / 650 | 시트 제목 |
| Body | 15 / 450 | 본문 |
| Caption | 12 / 500 | 라벨, 메타 |
| Numeric | `font-variant-numeric: tabular-nums` | 통계, 날짜 |
| Stamp | JetBrains Mono 600, 대문자 + 자간 12% | 도장 안 텍스트에만 |

### 형태와 모션

- 4pt 그리드, 화면 좌우 여백 16px
- 라운드: 카드 16, 시트 24, 알약 999
- 그림자는 1단계만 (`0 8px 24px rgb(0 0 0 / .08)`). 테두리와 그림자를 동시에 쓰지 않음
- 모션: 기본 200ms ease-out / 시트는 스프링 / 도장 "쾅"은 scale 1.6→1, 260ms + 햅틱
- `prefers-reduced-motion`이면 애니메이션 생략

### 도장 v2 (레퍼런스 반영)

- 이중선 테두리 + 타이포만 사용. 이모지와 일러스트 금지
- 모양 5종(원, 타원, 사각, 팔각, 육각)은 도시 id 해시로 고정
- 내부 레이아웃 (위에서 아래로): `CZECHIA`(6.5, 자간 넓게) / `PRAHA`(16, 굵게) / `13 OCT 2026` / 구분선 / `50.0755° N` / `14.4378° E`
- 잉크 결: 아주 미세한 점 빠짐만 (SVG feTurbulence 마스크). 번짐이나 형태 왜곡은 금지
- 색: 기본 `--accent`, **히든젬(tier 3 큐레이션) 도시만 `--gold`**
- 찍히는 각도는 ±9° (방문 id로 고정)

### 국기

- [`flag-icons`](https://github.com/lipis/flag-icons) (MIT)의 1×1 SVG를 원형으로 잘라서 사용
- 미방문: `grayscale(1) opacity(.45)`, 방문: 컬러 + 2px 흰 테두리

## 6. 접근성 & 품질 기준

- 대비 4.5:1 이상 (WCAG AA), 터치 영역 44px 이상
- 지도 마커는 키보드 포커스와 스크린리더 라벨 지원
- 다크 모드 자동 전환 (시스템 설정 따름)
- 첫 화면 LCP 2.5초 이내 (4G 기준), Lighthouse PWA 통과
