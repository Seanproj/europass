# Euro Passport — 기획 제안서 (v0)

> 독일에서 지내는 동안 유럽 도시를 하나씩 "클리어"하면서, 남들이 봐도 감각 있는 여행 기록을 남기는 플랫폼

---

## 1. 플랫폼 선택지 비교

| 선택지 | 장점 | 단점 | 추천 |
|---|---|---|---|
| **① 웹앱 (PWA) + GitHub Pages** ← *현재 구현* | 무료 호스팅, 폰 홈 화면에 앱처럼 설치, 디자인 100% 자유, Claude Code로 바로 개발 | 기본 저장소가 브라우저라 백업이 필요함 | ⭐⭐⭐ 시작용 |
| ② 웹앱 + Supabase/Firebase | 여러 기기 동기화, 친구가 내 여권 페이지 열람 가능, 사진 클라우드 저장 | 로그인/DB 설정 필요(무료 티어로 충분) | ⭐⭐⭐ 2단계 |
| ③ Notion 템플릿 | 코딩 없음, 금방 시작 | "도장 깨기" 재미, 지도, 애니메이션 표현이 어려움 | ⭐ |
| ④ 인스타그램 전용 계정 | 공유가 가장 쉬움 | 정복률·지도·배지 같은 게임 요소 없음 | ➕ 앱의 **공유 카드**와 함께 쓰면 좋음 |
| ⑤ 네이티브 앱 (React Native/Flutter) | 위치 기반 자동 체크인, 푸시 알림 | 개발·스토어 등록 부담이 큼 | 나중에 |

**결론:** ① PWA로 지금 바로 쓰기 시작하고 → 기록이 쌓이면 ② 클라우드 동기화 + 공개 프로필 페이지로 확장. 인스타그램은 앱이 만들어 주는 **공유 카드 이미지**를 올리는 채널로 활용.

---

## 2. 컨셉: "여행자 공화국 여권"

- **비주얼:** 네이비 + 골드 여권 표지, 크림색 종이 질감, 잉크 번짐이 있는 도장
- **핵심 루프:** 도시 방문 → 기록 작성 → **"쾅!" 도장 애니메이션** → 지도에 비행 궤적 생김 → 배지 획득 → 공유 카드
- **독일 거주자 특화:** 거주 도시를 출발점으로 거리 계산, "기차 당일치기 / 주말여행 / 야간열차 / 비행기" 추천, "다음 주말, 여기 어때요?"

## 3. 기능 아이디어 (✅ = MVP에 구현됨)

### 수집 & 게임
- ✅ 47개 주요 도시 · 25개국, 6개 권역으로 나눈 여권 페이지
- ✅ 도시마다 모양/잉크 색/각도가 다른 **고유 도장** (자동 생성 SVG)
- ✅ 18종 배지 — 첫 발자국, 지중해의 햇살, 북유럽 감성, 독일 마스터, 사계절 여행자, 수도 컬렉터…
- ✅ 정복률, 방문 국가 수, 누적 이동거리(왕복 기준)
- 💡 **시즌 챌린지**: "크리스마스 마켓 5곳", "여름 해변 3곳" 같은 기간 한정 미션
- 💡 **레어 도장**: 작은 도시(할슈타트, 브뤼헤 등)는 금박 테두리 도장
- 💡 **도시 추가**: 목록에 없는 도시를 직접 추가 (지도 클릭으로 좌표 지정)

### 기록
- ✅ 날짜, 기분 이모지, 별점, 한 줄 요약, 일기, 사진(자동 압축)
- ✅ 재방문 기록 (같은 도시 여러 번)
- ✅ 월별 타임라인
- 💡 사진 EXIF에서 날짜·위치 자동 추출 → 도시 자동 매칭
- 💡 여행 경비 기록 → "1유로당 행복도" 통계
- 💡 맛집/카페 핀 (도시 안의 서브 체크리스트)
- 💡 기차표/항공권 사진을 "티켓 스텁" 디자인으로 보관

### 시각화 & 공유
- ✅ 확대/이동 가능한 유럽 지도, 방문국 색칠, 집에서 뻗어나가는 비행 궤적 애니메이션
- ✅ 인스타 피드용(1080×1350) **공유 카드** 이미지 생성 + 네이티브 공유
- 💡 연말 결산 "My Euro Wrapped" 스토리 카드 (가장 멀리 간 곳, 최고 별점 도시, 월별 그래프)
- 💡 공개 여권 페이지 URL (`/u/이름`) — 친구가 내 여권 구경
- 💡 엽서 모드: 사진 + 손글씨 폰트 + 우표 → 엽서 이미지로 저장

### 데이터
- ✅ 브라우저(IndexedDB) 저장 + JSON 백업/복원
- ✅ 오프라인 동작 (서비스 워커)
- 💡 Supabase 로그인 + 클라우드 동기화
