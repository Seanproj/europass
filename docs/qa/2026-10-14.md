## 2. 화면 점검 (`scripts/qa-sweep.mjs`)

실제 지도 타일을 켠 개발 서버에서 화면 15개 × 4가지(360 라이트, 390 라이트, 390 다크, 1280 데스크톱) = 60번 점검.

화면: 빈 홈 · 검색 · 홈(접힘/반쯤) · 도시 목록 · 나라 상세 · 도시 상세 · 엽서 · 기록 편집 · 사진 보기 · 프로필 · 여권 넘기기 · 설정 · 공유 카드 · 연말 결산

| 점검 | 결과 |
|---|---|
| 콘솔 오류 · 페이지 오류 | 없음 |
| 실패한 요청 | 화면을 옮길 때 취소된 지도 타일(`ERR_ABORTED`)뿐 — 정상 |
| 가로 스크롤 | 없음 (360px 포함) |
| 접근성 (axe, WCAG 2 A/AA) | 위반 없음 |
| 44px 미만 터치 영역 | 아래 3곳 → 수정 |

## 3. 발견하고 고친 것

| 문제 | 원인 | 수정 |
